# Hero image brief — Chapter 13: Case: Engineer Who Ships — Backend to AI

**Subject.** A clean isometric or near-isometric composition rendering a single layered software stack as a vertical column — database tier at the bottom, microservice tier mid-stack, API gateway tier above, AI/RAG inference tier near the top, observability/dashboard tier crowning it. Each tier is rendered as a discrete card with subtle depth, connected by clear data-flow lines. The columns reads as one engineer's hand on the entire stack rather than as siloed boxes.

**Mood.** Technical, calm, confident. Late-night-engineer-at-the-monitor energy without the cliché. The image should feel like infrastructure that is *quietly working* — no alert dialogs, no error states, no urgency. Production-stable.

**Negative space for title overlay.** Reserve the left third or upper-left quadrant for chapter title and case-tagline overlay. The stack should sit right-of-center, weighted to the right edge, so the title sits in clean negative space against the background.

**What the teaching image should make most visually prominent.** The *connectedness* of the layers — visible flow lines crossing every boundary, no missing edge, no broken handoff. The viewer should read the image as *one engineer who can be trusted with the entire path* rather than as five specialists each owning one tier. A single understated metric badge in one corner ("3s → 450ms" or "85% latency reduction") is the only typographic flourish; the rest of the image carries no visible text.

**Palette.** Deep navy backdrop (`#0A1628`), card surfaces a slightly lighter navy (`#0F2040`), data-flow lines and the prominent accent in electric blue (`#1E6FFF`) with sky-blue highlights (`#4D91FF`), text and key strokes in pure white. Minimal warm tones; the palette is the brand's, applied without exception.

**Style references.** Stripe's documentation diagrams, Linear's marketing illustrations, Vercel's product graphics — flat-but-dimensional, technical without being industrial, restrained palette, generous negative space. Avoid stock-photo realism and avoid 3D renders that read as marketing flourish.

**What to avoid.** No isolated tools as logos (no Kubernetes hexagon, no LangChain icon, no AWS marks). No human figure. No keyboard, no monitor, no laptop. No code on screen. No motion blur or speed lines. No "AI brain" iconography.
