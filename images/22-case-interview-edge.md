# Hero image brief — Chapter 22: Case: InterviewEdge — The Brand Made Deployable

**Subject.** A high-contrast composition rendering a stylized terminal window as the central object — the brand's primary visual register — with the prompt line `$ karthik --tool interviewedge` typed at the cursor and a four-line response below showing *paste a JD · get tailored prep · deployed · GPT-4o Mini · free · zero data stored*. The terminal sits centered against a deep-black ground; status indicators (`● red ● yellow ● green`) appear at the top of the terminal window in the conventional macOS-window-control position. A second smaller terminal panel below or beside the first shows the Brand Story chapter headers as filenames in a directory listing — *the-beginning.md, the-scale.md, the-shift.md, the-mission.md*.

**Mood.** Production-engineering-precise, considered, taste-driven. The composition should feel like a senior engineer's working environment captured at rest — calm, observable, no alerts. The Craftsman archetype's *long-term commitment* register expressed as visual restraint.

**Negative space for title overlay.** Reserve the upper-left quadrant for chapter title and case-tagline overlay. The terminal window sits weighted to centre-right, leaving the upper-left in deep-black negative space for typography. The single electric-orange accent appears only on one detail (the cursor block, or the terminal-window's status-active indicator, or one keyword in the response output).

**What the teaching image should make most visually prominent.** The *terminal-window-as-portfolio* — the viewer should read the image as *this brand IS its visual system*; the terminal is not decoration around content, it is the content. The four chapter headers in the second panel argue the brand-story-as-documentation-page commitment.

**Palette.** Deep Black `#0A0A0A` ground; Dark Surface `#1A1A1A` for the terminal-window fill; Crisp White `#FFFFFF` for the active typography; Slate Gray `#6B7280` for the inactive directory listing and secondary text; Electric Orange `#F97316` exclusively on the single accent (cursor or status indicator). No additional saturated colors. Fira Code for all monospace type; Georgia only if any non-monospace headline is needed (which the composition should avoid).

**Style references.** The terminal-screenshot register of Stripe's CLI documentation; the considered-restraint of Vercel's CLI marketing pages; the editorial-document register of Anthropic's technical-blog typography. Avoid the saturated marketing register of generic SaaS hero graphics and avoid stock-photo realism on any element.

**What to avoid.** No literal Streamlit, OpenAI, or GPT-4o Mini logos. No human figure. No actual code beyond the prompt-and-response micro-type. No "AI brain" iconography. No motion blur, no glow effects, no particle scatter. No additional accents beyond the one orange detail. The terminal window and the dark surface around it are the entire composition.
