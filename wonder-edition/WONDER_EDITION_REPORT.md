## Structure Compliance

Every file follows the mandatory nine-section structure:

1. **The Strange Question** — opens with a specific case that creates genuine surprise
2. **First Intuition** — articulates the intuitive wrong answer, includes Planning metacognitive prompt
3. **The Surprise** — evidence that breaks the intuition, includes Monitoring metacognitive prompt
4. **The Hidden Structure** — explains the mechanism, includes Misconception Checkpoint
5. **Try Looking At It This Way** — TWA analogy with six labeled sections (Target, Base, Features, Commonalities, Boundaries, Conclusions)
6. **Where The Analogy Breaks** — identifies specific failure modes of the analogy
7. **Small Discovery** — non-computing domain, follows data → pattern search → prediction → `---` separator → revelation order
8. **What This Changes** — evaluation prompt, Practice Bridge, connection to next chapter
9. **Wonder Questions** — five questions, ends with four-part Precision Summary (What the concept is / What it explains / What it does NOT mean / What comes next)

All files also include an **Author Notes** section with three required parts: core misconception targeted, analogy base domain, Bloom's arc.
